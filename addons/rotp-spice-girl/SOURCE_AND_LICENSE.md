## Spice Girl source and license

This 1.21.1 migration is derived from the unique Stage 0 artifact:

- File: `RotP-辣妹-1.3-tournament.jar`
- Size: `3042420` bytes
- SHA-256: `6D2429EDFF3FD729DA339A23B2F1E6D4862C92AB2296F7056E8BD8A789438151`
- Legacy mod id: `rotp_sg`
- Legacy author: `TheDoGGy`
- Legacy license declaration: `GNU GPL v3.0`

The Java implementation was reconstructed from canonical CFR mirror
`067_RotP-辣妹-1.3-tournament`. Mirrors `068` and `069` were independently
compared and contain the same 22 files, 58,274 bytes, and normalized tree
SHA-256
`B5172E8F00B1F5A2CA9C25AFB9DF5C5434321EFC76B1253111CBD4E8B8158304`.

The Stand icon, effect icon, action icons, and active sound clips are
byte-identical extractions from the canonical JAR. The Stand geometry,
animation identifiers, UV atlas, and main texture were upgraded for the
current H1 model contract. Per-face UV keys reproduce the core Gecko loader's
donor box-UV face ownership and top-face orientation. The 128x source texture hash, 256x target texture
hash, conversion evidence, and exclusions are recorded in
`META-INF/spice-girl-source-manifest.json` and
`migration/art/art-upgrade-evidence.json`.
All 16 legacy animation clips remain present. The additional looping
`wall_climb` clip is a migration-authored H1 Stand animation generated by
`migration/tools/add-wall-climb-animation.mjs`; it does not reuse a
third-party animation donor.

The migrated source code is distributed under GNU GPL v3.0. Reused assets
remain subject to the source package's GPL v3.0 declaration and applicable
third-party rights.

### Inert legacy archive

The canonical JAR also contains ten entries retained byte-for-byte for
provenance: one Trish skirt item model, four skirt textures, the unrelated
`chariot_requiem_ost.ogg`, the donor-registered
`trish_arividerchi.ogg`, the legacy Mixin descriptor and refmap, and the
legacy `pack.mcmeta`.

The current module has no skirt item or renderer registration and no Mixin
configuration. The skirt resources, unrelated Chariot Requiem OGG, and
legacy metadata therefore remain inert under
`assets/rotp_sg/legacy_archive/`. The Arrivederci OGG is also restored
byte-exactly at its original active path together with the SoundEvent that
the donor registered. Legacy loader metadata is renamed within the owner
archive, so it cannot be discovered as a root Mixin/refmap or pack
descriptor.

The donor `rotp_sg:spice_girl_ost` `OstSoundList` is separately reachable
through the Spice Girl Stand and is restored with its seven generated
SoundEvents. The canonical JAR has no matching `ost/spice_girl_ost.ogg`, so
the list remains intentionally silent and neither archived OGG is repurposed.

`migration/restore-legacy-resources.ps1` verifies the canonical JAR and
recreates the archive deterministically.
`migration/legacy-resource-retention.json` locks all ten source/target
paths, byte counts, categories, and SHA-256 values.
