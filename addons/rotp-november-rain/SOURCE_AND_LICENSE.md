## Source and license

This module ports the November Rain addon from:

- Source artifact: `[十一月雨]November-Rain-1.0.jar`
- SHA-256: `EE86C1E4922B419AE5640538293CF732A50C8B1DEF1433A42DD4C560A9D1C109`
- Original mod ID: `november-rain-addon`
- Original authors: `Ptitboo83, the one who will make the texture`
- Original metadata license: `GNU GPL v3.0`

The 1.21.1 port normalizes the mod ID to `rotp_november_rain`, migrates the
registration and action lifecycle to NeoForge 21.1, and adapts the original
resource model to the current ROTP stand-skin renderer.

The donor geometry is retained as provenance, not as a finished visual
reference. It identifies itself as `geometry.unknown`, uses placeholder
`ExampleStandModel` code and six flat placeholder bones, and places boxes over
an approximately 100-by-79 model-unit span. That prototype directly caused
the detached plates, oversized columns, and unrelated rods visible after the
initial resource-only migration.

Production geometry is deterministically generated by
`migration/generate-coherent-geometry.ps1` from the module's existing
128-by-128 donor texture. It uses no external image or model asset. The rig is
a connected 30-bone/35-cube block model: a wide central shell and face mask,
a four-stage downward taper, four symmetric hip/knee/shin/foot chains, and six
upper leaf plates attached to the carapace.
